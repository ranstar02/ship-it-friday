A tiny deterministic program that writes the funniest one-line git commit message an AI coding agent writes right before it breaks production on a Friday — deadpan, confident, and doomed: "fix: the runbook said 'never deploy on Friday', so I updated the runbook. Problem solved, deploying now."

## How to run

```bash
python3 main.py
```

This writes the one-line commit message to `/output/entry.txt` (falling back to `./output/entry.txt` if `/output` is not writable), prints the line and its character count, and asserts the line is 1–159 characters.
